# 🛡️ AdGuard Privacy Lab

An independent educational project dedicated to exploring
online privacy, ad blocking, web tracking, and cybersecurity
through research, practical experiments, and documentation.

> **Disclaimer:** This is an independent learning project.
> It is not affiliated with, sponsored by, or endorsed by AdGuard.

## 📖 Project Overview

AdGuard Privacy Lab is a personal learning initiative focused
on understanding how modern privacy technologies protect
internet users.

The project will explore advertising networks, tracking
technologies, DNS filtering, and tools designed to improve
online privacy and security.

The goal is to combine technical research with hands-on
experimentation while documenting discoveries and
developing practical technical skills.

## 🎯 Project Goals

- Understand how online advertising and tracking work.
- Explore AdGuard's privacy and filtering technologies.
- Learn the fundamentals of DNS-based ad blocking.
- Investigate common web tracking techniques.
- Develop practical troubleshooting and testing skills.
- Document experiments, observations, and findings.
- Share educational resources with other learners.
- Identify opportunities for constructive feedback.

## 🔬 Planned Experiments

### 1. Ad Blocking Effectiveness
Investigate how content-blocking tools identify and
filter advertisements across different websites.

### 2. Web Tracking and Privacy
Explore common tracking technologies, including
third-party cookies, tracking scripts, and web beacons.

### 3. DNS Filtering
Research how DNS-level filtering works and how
services such as AdGuard DNS can help block
unwanted domains.

### 4. Performance and Usability
Examine how privacy tools may affect website
loading times, functionality, and browsing experience.

### 5. Filter Lists and Custom Rules
Learn how filtering rules work and investigate
how custom rules can improve blocking accuracy.

## 🧪 Testing Methodology

When experiments begin, each test will document:

1. **Objective:** What is being investigated?
2. **Environment:** Which browser, operating system,
   and tools are being used?
3. **Procedure:** What steps were performed?
4. **Observations:** What actually happened?
5. **Results:** What conclusions can be supported?
6. **Limitations:** What remains uncertain?
7. **Next Steps:** What should be investigated further?
